## How to Contribute

1. **Fork the repository** to your own GitHub account.
2. **Clone your fork** to your local machine:
   ```bash
   git clone https://github.com/your-username/Solar-Radiation-Prediction-using-Saudi-Arabia-Dataset.git
   ```
3. **Create a new branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes and **commit them** with clear, descriptive commit messages.
5. **Push your branch** to your forked repository:
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request** on the main repository. Describe your changes and link any relevant issues.

## Reporting Issues

If you find a bug or want to request a feature:

- Check if the issue already exists in the [Issues](../../issues) section.
- If not, open a new issue describing:
  - What the bug or feature is
  - Steps to reproduce (if applicable)
  - Any relevant logs or screenshots

## Submitting Pull Requests

- Ensure your branch is up to date with `main`.
- All checks and tests must pass before merging.
- Be descriptive in your Pull Request:
  - What changes have you made?
  - What problem does it solve?

## Coding Guidelines

- Follow consistent code style (e.g., PEP 8 for Python).
- Write clear, concise comments and documentation.
- Add or update tests as necessary.
- Use meaningful variable and function names.

## Code of Conduct
